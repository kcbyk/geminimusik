Model tarafı

gemini_service.dart sistem istemi artık görselleri yanıt gövdesine Markdown olarak yerleştirmeyi, başlıklarda tek emoji kullanmayı ve albüm/parça listelerini album / tracklist / artist bileşenleriyle üretmeyi söylüyor. Görsel URL'si yoksa görsel üretmiyor.

Bu dosya yalnızca tasarım referansıdır (statik HTML). Uygulamanın kendisi Flutter'da çalışır: flutter test ile 156 test + 16 yeni arayüz testi doğrulanmıştır.
